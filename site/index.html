Every answer comes with a receipt.

plus runs Claude Code, Codex and other coding tools on Surplus Intelligence, a marketplace for spare AI capacity. After each answer it shows what you paid and what list price would have been.

curl -fsSL https://raw.githubusercontent.com/adamtpang/plus/main/cli/install.sh | sh

Needs Node 18 or newer. It installs two small files you can read first. No telemetry.

plus ask
$ plus ask "What is a spend cap?" -m auto

A spend cap is a preset limit on how much can be spent, after which further spending is blocked.

Bring your own agent

One word in front of the tool you already use.

plus sets the tool's own settings and starts it. It checks your key first, so a bad key stops with a clear message instead of a confusing error from inside the tool. Nothing is written to any config file.

Measured, not claimed

The same ten prompts through three routers.

plus bench sends identical prompts through Surplus, OpenRouter and Router by Ramp, checks every answer, and reports what each one actually charged. This is one real run: eight models, 24 November 2026, dollars per 1M tokens.

  • Surplus answered every request and was at least half the price on seven of eight models.
  • It was not the cheapest on every model. On mimo-v2.6-pro, OpenRouter cost less, because most of its input came from cache.
  • It was slower to start. First token took 1.2 to 4.6 seconds on Surplus against 0.6 to 6.8 on OpenRouter, by model.
  • One Surplus answer was wrong (a long-context lookup on the cheapest model). One miss in 80 is not a pattern.
  • Ten requests per model per router, one machine, one day. Prices on Surplus move with its market, and Ramp is shown at its list price. Run it yourself before quoting it: plus bench --live -m shortlist

The whole tool

Small enough to read in one sitting.

One JavaScript file, no dependencies, 73 tests that run on Windows, Mac and Linux. Sign-up and top-up happen in the terminal too.

Said plainly

What it does not do.

A tool that handles your key and your money should tell you where it stops.

Careful with money

  • A spend cap. PLUS_SPEND_CAP=0.50 stops ask, compare and bench once the day's spending reaches it.
  • It never hangs. A silent connection is dropped after a set wait, and a cut-off answer says so.
  • It retries only when safe: before any of the answer has printed, at most twice.
  • Refusals are shown in Surplus's own words, not as a bare error code.

Honest limits

  • Your key is stored as plain text in a file in your home folder, not in the system keychain.
  • It cannot prove which model answered. Neither can Surplus yet. The bench checks the answer is right.
  • The spend cap counts only what plus itself spends, not tools you start with it.
  • It needs Node. There is no single-file binary yet.
  • It is unofficial. Not made or endorsed by Surplus Intelligence.
